# Rivet Web

Веб-консоль [Rivet](https://github.com/PavluninVladimir/rivet) — оркестратора автономной разработки с помощью AI-агентов.

Стек: **React**. Эталон UX — дизайн-прототип `agent-orchestration-console.html` в основном репозитории.

Требования и спецификации ведутся в основном репозитории: [`rivet/openspec/`](https://github.com/PavluninVladimir/rivet/tree/main/openspec) — в частности, capability `console`.

Код ещё не создан — проект на стадии формирования требований.
